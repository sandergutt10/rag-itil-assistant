# RAG ITIL Bot

RAG-система для поиска технической документации и решений на основе практик ITIL 4.

## Технологический стек

- Python
- Docker и Docker Compose
- Ollama
- Gemma 2:2b
- Векторная база данных
- Embedding-модель

## Возможности

- Семантический поиск по базе знаний.
- Поиск технических решений по запросам пользователей.
- Использование локальной LLM через Ollama.
- Оценка качества поиска с помощью Recall@3 и MRR.

## Структура базы знаний

База знаний содержит статьи по следующим практикам ITIL 4:

- Incident Management
- Problem Management
- Change Enablement
- Knowledge Management
- Service Desk
- Service Level Management

## Запуск проекта

1. Клонировать репозиторий.
2. Запустить Docker Compose.
3. Загрузить необходимые модели Ollama.
4. Установить зависимости Python.
5. Запустить приложение.

## Тестирование

Для оценки качества поиска используются метрики:

- Recall@3
- Mean Reciprocal Rank (MRR)

## Назначение

Проект разработан для демонстрации применения технологии RAG для поиска информации в технической базе знаний.
